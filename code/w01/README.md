**目标**：把 8 个基础知识点用一遍，练到「不看教程能写出来」。
**预计耗时**：每题 15~40 分钟，分 3~4 天做完。
**规则**：
1. 每题**自己跑通**再往下，不要攒着一起调试。
2. 卡住先自己试 **20 分钟**，再来问我，问的时候带上「报错原文 + 我试过什么」。

4. 允许查语法，不允许让 AI 生成整段代码。

文件命名：`01_temp.py` … `05_wordcount.py`，都放在 `code/w01/` 下。

## 1. 温度换算器 —— 变量、类型转换、f-string

**要求**：用 `input()` 读一个摄氏温度，换算成华氏温度（F = C × 9/5 + 32），输出保留 1 位小数。
如果用户输入的不是数字，输出提示「请输入数字」，**不要让它崩溃**。

**运行示例**：
```
请输入摄氏温度：37
37.0°C = 98.6°F
```
```
请输入摄氏温度：abc
请输入数字
```

**知识点**：`input`、`float()`、`try/except`、`f"{x:.1f}"`

**提示**：`input()` 拿到的永远是字符串。

## 2. 密码强度检查 —— 条件判断、字符串

**要求**：读一个密码，按下面的规则输出「弱 / 中 / 强」：

| 条件 | 等级 |
|---|---|
| 长度 < 6 | 弱 |
| 长度 ≥ 6，且同时包含字母和数字 | 中 |
| 长度 ≥ 10，且同时包含字母、数字、符号 | 强 |
| 其它情况 | 中（长度 ≥ 6）或弱（长度 < 6） |

**运行示例**：
```
输入密码：abc123
强度：中
```

**知识点**：`len()`、`in`、`isalpha()` / `isdigit()` / `isalnum()`、`any()`、`and` / `or`

**验收**：`abcd` → 弱；`abc123` → 中；`abcdefgh1!` → 强。

## 3. 猜数字 —— 循环、break、随机数

**要求**：程序随机生成 1~100 的整数，玩家最多猜 7 次。每次猜测后提示「太大」或「太小」。
猜中时输出猜测次数；7 次用完还没中，输出正确答案。

**运行示例**：
```
第 1 次猜：50
太小了
第 2 次猜：75
太大了
...
恭喜！你用了 4 次猜中
```

**知识点**：`random.randint`、`while` / `for`、`break`、计数器

**提示**：`import random`，然后 `random.randint(1, 100)`。

## 4. 成绩统计 —— 列表、循环、排序

**要求**：给定 `scores = [78, 92, 65, 88, 95, 71]`，输出：

1. 平均分（保留 2 位小数）
2. 最高分、最低分
3. 及格率（≥ 60 分的人数占比，百分比保留 1 位，例如 `83.3%`）
4. 从高到低排序后的列表

**禁止**使用 `statistics` 模块和 `sum()`？—— `sum()` 可以用，但**平均值、最大值、最小值都要自己写循环算一遍**，然后再用内置函数验证结果是否一致。

**知识点**：`for`、累加变量、`sorted()` / `.sort()` 与 `reverse=True`、列表切片

## 5. 词频统计（本周大关卡）—— 字典、字符串处理、文件读写

**要求**：读一个 `.txt` 文件（自己造一个 200 词以上的英文文本），统计每个单词出现的次数：

- 统一转小写
- 去掉标点符号（`, . ! ? ; : " '` 等）
- 按出现次数从高到低，输出前 10 个单词及次数
- 把结果写进同目录的 `result.txt`

**运行示例**：
```
1. the      12
2. python    8
3. is        7
...
（已写入 result.txt）
```

**知识点**：`open()`、`read()`、`split()`、`.lower()`、`.strip()`、字典 `get()`、`sorted(..., key=..., reverse=True)`、文件写入

**提示**：处理标点最简单的方式是 `s.replace(",", " ")` 逐个替换，或者用 `str.translate()`。先用笨办法做出来，别一开始就追求优雅。

**验收**：这是路线图里「阶段 A」的终极验收标准——关掉教程，从空白文件开始，一次写完并能跑通。
